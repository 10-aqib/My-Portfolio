1Tap

Instant Cross-Device File, Text & Link Sharing

Zero-signup peer-to-peer sharing tool allowing users to temporarily connect devices and share text, URLs, and files in real time. Features 6-digit room codes, QR pairing, live presence counters, and auto-expiring temporary rooms for privacy.

Problem: Sharing files or text between devices typically requires accounts, cloud uploads, or cables. Approach: Used Supabase Realtime channels to create ephemeral, zero-signup P2P rooms identified by 6-digit codes and QR pairing — no data stored after room expiry. Result: Instant cross-device sharing supporting up to 100 MB transfers, live and publicly testable with no sign-up.

Duplicate, Unused & Heavy File Disk Analyzer

High-performance storage intelligence tool designed to detect duplicate, unused, and heavy files consuming valuable disk space. Features interactive D3 storage visualizers, virtualized file lists, command palette, and one-tap cleanup workflows.

Problem: Disk analysis tools are either CLI-only or bloated with paid features, leaving non-technical users unable to reclaim space easily.
